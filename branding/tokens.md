# Avalith Brand Tokens (extracted from Avalith_Branding_Guide.pdf, Sept 2026)

## Colors
| Token | Hex | Use |
|---|---|---|
| `--bg` | #0B0A11 | app background |
| `--card` | #0E0D15 | cards, secondary buttons |
| `--panel` | #131119 | panels |
| `--warm` | #1D1215 | card icon backgrounds |
| `--red` | #D5252F | primary accent, brand dot |
| `--green` | #3ECF8E | positive status |
| `--ink` | #FFFFFF | primary text |
| `--soft` | #8E8C99 | secondary text |
| `--muted` | #56545F | tertiary text |
| `--line` | rgba(255,255,255,.08) | borders |
| `--lineh` | rgba(255,255,255,.18) | stronger borders |

## Typography
- **Inter** — 800 H1/H2, 700 subtitles/labels, 600 buttons, 400–500 body.
- **JetBrains Mono** — 700 nav items / badges / eyebrows, 400 secondary mono text.

## Brand marks
- Logo: `avalith.` lowercase with a **red period**. Compact: `a.` (collapsed sidebar).
- Eyebrows in `// snake_case`, JetBrains Mono, red.
- **Red period** ends H1/H2 titles instead of punctuation.
- Name is always `avalith.` never "Avalith" in brand/UI.
- Dark theme by default (internal products).

## UI patterns
- Primary button: `--red` bg, `--ink` text, Inter 600.
- Secondary button: `--card` bg, `--soft` text, `--lineh` border.
- Card: `--card` bg, `--line` border, small radius.
- Card icon: rounded square, `--warm` bg, `--red` icon.
- Input/select: `--bg` bg, `--line` border, focus border `--red`.
- Badge/pill: semi-transparent status color bg, status-colored text.
- Sidebar item: JetBrains Mono 700; active = bg rgba(213,37,47,.12) + 3px `--red` bar.
