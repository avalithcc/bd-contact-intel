Cómo se cotejan las filas

  1. Empresa propia (nombre o dominio de Avalith) → se omite.
  2. Mismo perfil de LinkedIn → se fusiona automáticamente.
  3. Mismo correo, verificado en ambos lados → se fusiona automáticamente.
  4. Mismo nombre + empresa → se crea, y el par pasa a la cola de revisión del administrador. Nunca se fusiona automáticamente.
  5. En cualquier otro caso → contacto nuevo. Para importaciones de LinkedIn, se agrega al BD como conectado.
